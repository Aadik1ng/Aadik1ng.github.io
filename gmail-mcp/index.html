Gmail Assistant Bridge

A personal tool by Aaditya Aaryan — not a public service.

What it is. Gmail Assistant Bridge is a self-hosted connector that lets the developer's own AI coding assistant read, search, organize, draft and send email in the developer's own Gmail account, on the developer's own computer. It is a single-user tool. It has no sign-up, no other users, and no shared backend.

What it does. On request from the developer, it can list and read messages, search the mailbox, apply labels and filters, create drafts, and send mail — each action initiated by the developer through their assistant.

How it connects. It talks to Gmail through Google's official API over OAuth, using the scopes gmail.modify and gmail.settings.basic. The OAuth token is stored only on the developer's machine.
