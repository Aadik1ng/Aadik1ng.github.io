Privacy Policy & Terms — Gmail Assistant Bridge

Last updated: 18 October 2026

What this application is

Gmail Assistant Bridge is a personal, single-user automation tool built by Aaditya Aaryan for his own use. It connects his own AI coding assistant to his own Gmail account so he can read, search, organize, draft and send his own email by instruction. It is not offered to other people, has no other users, and is not a commercial service.

What data it accesses

Using Google's Gmail API with the scopes gmail.modify and gmail.settings.basic, the tool can access the contents and metadata of messages in the developer's own mailbox, labels and filters, and can create drafts and send messages as the developer. It accesses only the account the developer signs in with.

How the data is used

Email data is used solely to carry out the actions the developer asks for in that moment — for example, finding a specific email, summarizing a thread, labeling a message, or sending a reply. The developer's AI assistant processes the relevant email content only to fulfill those requests.

Storage, sharing and retention

The tool runs on the developer's own machine. The only credential it stores is the OAuth token, kept locally in a file readable only by the developer's user account. It does not keep a separate database or copy of email content, does not sell or share any data, and does not transmit email content to any third party other than the Google and AI-assistant APIs required to perform a requested action. Email data is not used to train any model.

Limited Use disclosure

Gmail Assistant Bridge's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Terms of use

The software is provided as-is, without warranty, for the developer's personal use. Access can be revoked at any time from the developer's Google Account permissions.
