Daily Larper Uploader

A personal publishing tool by Aaditya Aaryan.

Uses YouTube API Services

What it does

I make short explainer videos about AI engineering: agents, retrieval, voice AI and LLM performance. This tool runs on my own computer and uploads those finished videos to my own YouTube channel, @daily_larper, as Shorts, so I don't have to upload each one by hand.

What it accesses

  • Uploads my own videos to my own channel (YouTube Data API videos.insert).
  • Reads my own channel's basic details and my uploads' processing status (channels.list, videos.list).
  • Nothing else. It has no other users, is not offered to anyone, and never accesses any other person's data.

Your data

The only credential it stores is the OAuth token for my own Google account, kept on my own computer. Access can be revoked at any time from Google account permissions.
